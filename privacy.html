Integritetspolicy för Mordarkivet

Den här integritetspolicyn beskriver hur information hanteras när du använder Mordarkivet.

Personuppgifter och konto

Mordarkivet kräver inget användarkonto och ber dig inte att lämna namn, adress eller telefonnummer för att spela.

Appen innehåller inte annonser och använder inte information för beteendebaserad reklam eller marknadsföringsspårning.

Spelprogression

Spelprogression och annan lokal spelinformation sparas i första hand lokalt på din enhet så att du kan återuppta påbörjade fall.

Om appen tas bort eller dess lokala data rensas kan denna information försvinna.

Fall och spelinnehåll

Mordarkivet använder Supabase som teknisk tjänst för att lagra och leverera fall, bilder och annat spelinnehåll.

När appen kommunicerar med tjänsten kan teknisk information som normalt följer med internettrafik behandlas, exempelvis IP-adress och tidpunkt för begäran.

Detta används för att tillhandahålla appens innehåll och inte för annonsering eller profilering.

Facit

Lösningar till fallen lagras separat från det vanliga fallinnehållet och hämtas när spelaren väljer att ta del av lösningen.

Analys och spårning

Mordarkivet använder för närvarande inte externa analysverktyg, reklam-SDK:er eller tredjepartstjänster för användarspårning.

Delning av uppgifter

Vi säljer inte personuppgifter och delar inte information med annonsörer. Teknisk information kan behandlas av tjänsteleverantörer som behövs för appens funktion.

Barn

Mordarkivet är inte utformat för att samla in personuppgifter från barn. Appen kräver inget konto eller att användaren lämnar personliga uppgifter för att spela.

Ändringar

Integritetspolicyn kan uppdateras om Mordarkivets funktioner eller tekniska tjänster förändras.
